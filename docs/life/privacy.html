ПРИВАТНОСТЬ

Политика конфиденциальности приложения Svaga Life (Svaga Games). Действует с 1 декабря 2026 года.

НА ТЕЛЕФОНЕ

Всё хранится в одном файле внутри приложения: герой, ритуалы, отметки, награды, боссы и снаряжение. Без входа в Svaga ID эти данные никуда не отправляются. Файл попадает в резервную копию Android вместе с остальными данными телефона, если она у тебя включена.

ШАГИ И СОН (HEALTH CONNECT)

С твоего разрешения приложение читает из Health Connect только два вида данных:

  • число шагов за сегодня — чтобы засчитать ритуал «Шаги»;
  • длительность сна за прошлую ночь — чтобы засчитать ритуал «Сон».

Пульс, вес, местоположение и другие данные о здоровье приложение не читает. Число шагов или часов сна сохраняется в отметке ритуала. Данные из Health Connect не используются для рекламы, не продаются и не передаются третьим лицам. Разрешение можно отозвать в любой момент в настройках Health Connect.

SVAGA ID — ПО ЖЕЛАНИЮ

Если войти в Svaga ID (это тот же аккаунт, что в Svaga Archive), на сервер Svaga Games отправляется копия сохранения героя. В неё входят и отметки ритуалов с числом шагов и часов сна. Копия нужна, чтобы герой переезжал на новый телефон.

Друзья из Svaga ID видят имя героя, его уровень, класс, расу и серию. Участники одного босса компании видят урон друг друга. Почта и пароль хранятся по правилам Svaga ID; пароль хранится только в виде хеша.

ЧЕГО НЕТ

Рекламы, сторонних трекеров и аналитики, продажи данных.

ОБНОВЛЕНИЯ

Версия с GitHub раз в несколько часов проверяет, вышла ли новая сборка. Для этого она обращается к api.github.com. Никаких данных о тебе при этом не передаётся.

КАК УДАЛИТЬ ДАННЫЕ

  • «Начать заново» в настройках удаляет героя с телефона и его копию из облака Svaga ID.
  • «Выйти» в карточке Svaga ID отключает синхронизацию.
  • Удаление приложения стирает данные на телефоне.
  • Сам аккаунт Svaga ID удаляется в приложении Svaga Archive. Вместе с ним удаляется и копия героя.
