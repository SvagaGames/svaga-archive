Svaga Emulator — политика конфиденциальности

Svaga Games · действует с 1 декабря 2026 года

Игры и сохранения

В приложении нет игр. Файлы игр (ROM) ты добавляешь сам. Они, как и сохранения и снимки состояния, хранятся только на телефоне и никуда не отправляются.

Svaga ID — по желанию

Если войти в Svaga ID (тот же аккаунт, что в Svaga Archive), на сервер Svaga Games отправляется:

  • какая игра запущена и сколько в неё сыграно — для времени игры в профиле Svaga Archive;
  • статус игры в твоей библиотеке, если ты его меняешь;
  • поисковые запросы по каталогу игр — чтобы найти игру и её обложку.

Без входа эмулятор работает полностью, ничего не отправляя на сервер Svaga Games.

Обложки

Обложки игр загружаются из открытого архива libretro-thumbnails на GitHub. GitHub видит обычный сетевой запрос, данных о тебе в нём нет.

Обновления

Версия с сайта Svaga Games раз в несколько часов проверяет на api.github.com, вышла ли новая версия. Версии из магазинов обновляет сам магазин.

Чего нет

Рекламы, сторонних трекеров и аналитики, продажи данных.

Как удалить данные

Удаление приложения стирает всё на телефоне. Аккаунт Svaga ID и связанные с ним данные удаляются в Svaga Archive: как удалить аккаунт.
